# Quiz AI Chrome Extension

A Chrome extension that generates interactive quizzes from any webpage content using artificial intelligence.

## Features

- Generate quizzes from any webpage content
- Multiple quiz types (Multiple Choice, True/False, Open-ended)
- Adjustable difficulty levels
- Customizable number of questions
- Interactive quiz interface with instant feedback
- Score tracking and answer review

## Installation

1. Clone this repository
```bash
git clone https://github.com/imfeniljikadara/quiz-ai.git
```

2. Open Chrome and navigate to `chrome://extensions/`
3. Enable "Developer mode" in the top right
4. Click "Load unpacked" and select the extension directory

## Usage

1. Click the Quiz AI icon while on any webpage
2. Select your quiz preferences
3. Click "Generate Quiz"
4. Take the quiz and check your understanding!

## Configuration

Before using the extension, you need to:

1. Get a Google API key from [Google AI Studio](https://makersuite.google.com/app/apikey)
2. Add your API key to `popup.js`

## Development

To modify or enhance the extension:

1. Make your changes to the source files
2. Reload the extension in Chrome
3. Test your changes
